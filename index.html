Doc2MD

Ubah DOCX & PDF menjadi Markdown yang hemat token untuk AI. Semua diproses lokal di browser, file tidak diunggah ke mana pun.

Tarik file ke sini atau klik untuk memilih.docx dan .pdf · bisa banyak file sekaligus · file .doc lama / Google Docs: simpan dulu sebagai .docx

Jika hasil memuat penanda [?], penanda halaman, atau teks OCR, kartu hasil akan menampilkan prompt pendamping yang perlu disalin ke AI. Setiap file menampilkan laporan verifikasi (kata hilang, halaman OCR, tabel terdeteksi). OCR berjalan di browser dan mengunduh data bahasa saat pertama dipakai, jadi lebih lambat. Belum ditangani: PDF multi-kolom (urutan baca bisa tertukar), file .doc lama (simpan sebagai .docx), garis bawah & warna.
